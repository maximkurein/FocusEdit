# START HERE — как работать в FocusEdit

FocusEdit — редактор для письма без отвлечений: всё, что вы сейчас не пишете, приглушено, файл на диске остаётся чистым текстом, а строку можно удержать по центру окна кнопкой печатной машинки (по умолчанию она выключена, текст начинается сверху). Здесь — как им пользоваться и основные приёмы. Сборка и запуск из исходников — в [BUILD.md](BUILD.md).

Связано: [README.md](README.md) · [BUILD.md](BUILD.md) · [CHANGELOG.md](CHANGELOG.md)

## Запуск

FocusEdit ставится в «Программы» и запускается как обычное приложение — из Launchpad, Spotlight или Dock. Файлы `.md`, `.fountain` и `.txt` можно открывать через **Открыть с помощью ▸ FocusEdit**.

Установить или обновить после изменений в коде:

```bash
cd ~/Project/rea-lab/work/uFocus/FocusEdit
./package.sh && ./install.sh
```

`package.sh` собирает DMG, `install.sh` ставит его в `/Applications` (прежняя копия уходит в Корзину) и открывает приложение. При первом запуске без файла открывается приветственный документ (Welcome) — он учит, пока вы его правите; повторно — **Help ▸ Welcome Tour** или палитра (⇧⌘P) «Open the welcome tour». `examples/welcome.md` — ещё одна короткая демонстрация (**File ▸ Open…**).

## Первые пять минут

1. Откройте `examples/welcome.md` и подвигайте курсор стрелками вверх-вниз: яркий только текущий абзац, остальные плавно гаснут.
2. Щёлкните кнопку-прицел в тулбаре: режимы идут по кругу — **Off → Sentence → Paragraph** (выкл → по предложению → по абзацу). Абзац — это текст до пустой строки; заголовок и каждый пункт списка (вместе со строками его продолжения) считаются отдельными блоками. Предложение может идти через несколько строк. Стрелка рядом с кнопкой открывает список.
3. Перейдите в конец, нажмите Return и наберите `- Ma` — появится серое продолжение слова. **Tab** принимает его.
4. Нажмите Return ещё раз — список продолжится сам. Return на пустом пункте завершает список.
5. Нажмите **⌘?** — откроется шпаргалка по клавишам для текущего типа документа.

Подсказки есть и у каждой кнопки тулбара: задержите над ней указатель. Иконка, окрашенная в акцентный цвет, означает «режим включён».

## Документы: какой формат выбрать

| Расширение | Для чего | Что включается |
|---|---|---|
| `.md`, `.markdown` | заметки, статьи, книги | подсветка Markdown, продолжение списков, outline по заголовкам, превью и экспорт в HTML |
| `.fountain` | сценарии | подсветка сцен и персонажей, подсказки `INT.`/`EXT.` и имён, outline по сценам |
| `.txt` | простой текст | только фокус-режимы и подсказки слов |
| `.rtf` | файлы TextEdit и Word | открывается как Markdown: жирный, курсив, заголовки, списки, ссылки становятся разметкой и при сохранении снова становятся оформлением RTF |

Режим определяется **расширением файла**:

- **⇧⌘N** (File ▸ **New File…**) ведёт по трём шагам: формат (`.txt`, `.md` или `.rtf`) → заготовка (пустой файл, заметка, список дел, протокол встречи) → имя и папка. Файл создаётся на диске и сразу открывается; если имя занято, будет `имя (2)`. Те же три шага есть в Windows-версии: `Ctrl+Shift+N`.
- **⌘N** создаёт простой текст. Чтобы сразу писать в Markdown или сценарий, берите **File ▸ New From Template ▸ Markdown** или **Fountain**: заготовка, подсветка, и при сохранении сразу предлагается `.md` / `.fountain`.
- Если сохранить документ под другим расширением (**Save As…** → `notes.md`), режим переключится сразу, переоткрывать файл не нужно.

На диск всегда пишется простой текст UTF-8. Жирный, курсив, цвета и приглушение — только отображение: в файле остаются ваши `**звёздочки**` и `#`, его откроет любой редактор.

> **Файл сам не перезаписывается.** Сохраняйтесь сами: **⌘S**. Точка в красной кнопке закрытия — есть несохранённые изменения; при закрытии FocusEdit спросит, сохранить ли. **File ▸ Revert to Saved** возвращает последнюю сохранённую версию. Раз в минуту несохранённый текст автоматически откладывается в сторону: после сбоя система предложит вернуть его при следующем запуске.

## Фокус-письмо

| Приём | Как | Клавиша |
|---|---|---|
| Подсветка текущего предложения или абзаца | кнопка-прицел в тулбаре (клик — переключить, стрелка — список) или **Modus ▸ Focus Highlighting** | своя, см. ниже |
| Держать строку по центру окна («печатная машинка»; по умолчанию выключено, текст сверху) | кнопка `A|` | ⌘T |
| Звуки печатной машинки | кнопка динамика | ⌘U |
| Полный экран без тулбара и меню | зелёная кнопка окна | ⌃⌘F |

В полном экране тулбар и меню прячутся; подведите указатель к верхнему краю — они появятся.

**Своя клавиша для режима подсветки.** Готовых клавиш у режимов нет, чтобы не мешать вашим сочетаниям. Назначить свою: **Системные настройки ▸ Клавиатура ▸ Сочетания клавиш… ▸ Сочетания клавиш для программ ▸ +**, программа — **FocusEdit**, название пункта меню — `Modus->Focus Highlighting->Sentence` (или `->Paragraph`, `->Off`), затем нажмите нужное сочетание. Оно появится рядом с пунктом меню сразу или после перезапуска FocusEdit.

**Приёмы:**

- **Черновик:** подсветка по абзацу + печатная машинка + полный экран. Глаза всё время в одной точке, написанное не отвлекает.
- **Редактура:** выключите подсветку (прицел → **Off**) и печатную машинку (**⌘T**) — видно весь текст.
- **Трудный абзац:** подсветка по предложению (прицел → **Sentence**) — работайте фразой за фразой.
- Все настройки — тема, шрифт, размер, режимы — запоминаются между запусками.

## Подсказки при наборе

**Серое продолжение слова** появляется сразу после ввода буквы, если:

- курсор стоит **в конце строки** (в середине строки подсказка не показывается, чтобы не наползать на текст);
- набрано хотя бы **2 буквы** слова.

Сначала предлагаются слова этого документа (от 4 букв, чаще встречающиеся — первыми), с 3 букв — ещё и системный словарь (русский и английский). Регистр набранного сохраняется: `Mark` → `Markdown`, `mark` → `markdown`.

| Клавиша | Действие |
|---|---|
| **Tab** или **→** | принять подсказку |
| **Esc** | убрать подсказку |
| **⌥Esc** | показать список всех вариантов |

В сценарии (`.fountain`) в начале строки заглавными: `IN` + Tab → `INT. `, а имена персонажей, уже встречавшиеся в тексте, подсказываются по первым буквам.

**Скобки и кавычки** `( [ { " ` « “` закрываются сами, курсор встаёт между ними:

- выделите текст и нажмите `(` или `"` — текст обернётся;
- если закрывающий символ уже стоит справа, его ввод просто перешагнёт через него;
- Backspace между пустыми `()` удаляет обе скобки;
- после буквы или цифры прямые кавычки не удваиваются (`12"`, `it's`).

**Списки в Markdown** продолжаются по Return:

| Строка | После Return |
|---|---|
| `- пункт` | `- ` |
| `9. пункт` | `10. ` |
| `- [x] готово` | `- [ ] ` |
| `> цитата` | `> ` |
| пустой пункт `- ` | маркер удаляется, список закончен |

Каждую функцию можно выключить в меню **Edit**: **Suggest Completions**, **Automatic Pairing**.

## Markdown

- **⌘B** жирный, **⌘I** курсив, **⌘K** ссылка — обёртывают выделение или вставляют пустую разметку с курсором внутри.
- **Edit ▸ Format**: заголовок, цитата, маркированный и нумерованный список — для всех выделенных строк сразу. **⌘]** / **⌘[** — сдвиг строк вправо и влево.
- **⌥⌘P** (или кнопка с глазом) — режимы по кругу: Edit (только текст) → Split (живое превью рядом, обновляется на каждую правку, прокручивается вместе с текстом) → Preview (только страница; открывается там, где стоял курсор). **Esc** в Preview возвращает к тексту — курсор встаёт на место чтения. Ссылки открываются в браузере.
- **File ▸ Export as HTML…**, **Export as PDF…**, **Print… (⌘P)**; **Edit ▸ Copy as HTML** — для вставки в почту или CMS.

**Правка с пометками (CriticMarkup)** — когда текст правите вы или кто-то другой, а решение принимается позже:

1. Выделите фрагмент → **Edit ▸ CriticMarkup ▸ Addition / Deletion / Highlight / Comment**. Получится `{++добавить++}`, `{--удалить--}`, `{==важно==}`, `{>>комментарий<<}`; замена пишется как `{~~было~>стало~~}`.
2. Пометки подсвечены цветом: зелёное — добавить, красное — удалить, янтарное — выделено, синее — комментарий.
3. **Accept Change** применяет правки, **Reject Change** отменяет.

> Accept и Reject работают с **выделением**, а если ничего не выделено — со **всем документом**. Если применилось лишнее, отмените через **⌘Z**.

## Сценарии (Fountain)

| Пишете | Получается |
|---|---|
| `INT. КВАРТИРА - НОЧЬ` или `.ЛЮБОЙ ТЕКСТ` | заголовок сцены (жирный, в outline) |
| `МАША` (строка заглавными) | персонаж |
| `(шёпотом)` | ремарка |
| `CUT TO:` или `> ТЕКСТ` | переход |
| `# Акт 1` | раздел (в outline) |
| `= синопсис`, `[[заметка]]`, `~песня` | синопсис, заметка, лирика |

Экспорт в PDF печатает текст как есть — сценарной вёрстки страниц пока нет.

## Навигация

- **Библиотека** — панель слева (**⌥⌘L** или левая кнопка тулбара): одна выбранная вами папка с текстами, показаны её подпапки и файлы `.txt`, `.md`, `.rtf`, `.fountain`; двойной клик открывает файл (по папке — раскрывает её). Папку выбирает кнопка **Choose Folder…** в пустой панели, кнопка с папкой в её заголовке, **Library ▸ Link Directory…** или перетаскивание папки на панель; она запоминается. Кнопка ↻ перечитывает папку (и при каждом показе панели она перечитывается сама).
- **Выход (⌘Q) с несохранёнными изменениями** всегда спрашивает: Save / Don't Save / Cancel, а для нескольких документов — Review Changes…
- **Перетащите файл** из Finder в окно — он откроется отдельным документом, а не вставится текстом.
- **Outline** (**⌥⌘O** или правая кнопка тулбара): заголовки Markdown или сцены Fountain; клик — переход к строке.
- **Поиск:** **⌘F** — найти, **⌥⌘F** — найти и заменить, **⌘G** / **⇧⌘G** — следующее и предыдущее, **⌘E** — искать выделенное.
- **File ▸ Open Recent** — недавние файлы.
- Под названием окна — число слов и время чтения; **View ▸ Hide Word Count** скрывает их.

## Внешний вид

- **Тема:** кнопка с полукругом в тулбаре или **View ▸ Theme**. Для редактора: System (как оформление macOS), Light, Dark, Sepia и PowerShell (тёмно-синий фон консоли PowerShell 7 и светлый текст). Для просмотра отдельно: Same as editor или своя тема; выбор запоминается. Пока свою не выбрали, просмотр повторяет редактор. Печать и PDF всегда тёмным по белому.
- **Своя тема:** **View ▸ Theme ▸ Edit Themes…** — имя, светлая или тёмная, четыре цвета: фон, текст, приглушённый текст, курсор. Тема появится в меню и сохранится.
- **Шрифт:** **View ▸ Font** — System, Monospace, Serif; **⌘+** / **⌘−** — размер.
- **Тулбар:** **View ▸ Customize Toolbar…** — убрать или переставить кнопки; **⌥⌘T** — скрыть совсем.

## Vim-режим (учебный)

**Modus ▸ Vim Mode (learning)** или кнопка с клавиатурой в тулбаре (в Windows — кнопка **Vim**) включает режимы Vim: Normal, Insert, Visual. Под текстом появляется учебная панель: режим, набранные клавиши, пояснение каждой команды и подсказка, как сделать быстрее. Работает и в русской раскладке. Режимы: `i` — печатать (INSERT), `Esc` — обратно в NORMAL, `v` — выделять, `:` — команды; справа на панели всегда подсказка, куда можно перейти. **Выйти из Vim-режима** в обычный редактор — кнопка **Exit Vim** на панели, команда `:novim` или снова пункт меню (а `:q` закрывает окно). Курс по урокам с упражнениями — [VIM_GUIDE.md](VIM_GUIDE.md), файл для практики — `examples/vim-practice.md`.

## RTF и FocusEdit по умолчанию

**RTF** (формат TextEdit по умолчанию) открывается как Markdown и сохраняется обратно в RTF:

| В RTF | В FocusEdit | Обратно в RTF |
|---|---|---|
| **жирный**, *курсив*, зачёркнутый | `**жирный**`, `*курсив*`, `~~зачёркнутый~~` | то же оформление |
| крупный текст (заголовок) | `#`, `##`, `###` — по размеру | Helvetica 24 / 18 / 14 pt |
| маркированный, нумерованный, вложенный список | `- пункт`, `1. пункт` | списки TextEdit |
| ссылка, моноширинный текст, абзац с отступом | `[текст](адрес)`, `` `код` ``, `> цитата` | то же |

Шрифты, цвета, подчёркивание, картинки и таблицы в Markdown не переносятся. Если в файле есть что-то из этого, FocusEdit сразу после открытия предупредит, что при сохранении оно пропадёт. Чтобы сохранить оригинал, используйте **File ▸ Save As…** с новым именем.

**Открывать `.txt` и `.rtf` в FocusEdit по двойному щелчку:** **FocusEdit ▸ Make Default Editor for .txt and .rtf**. Работает только у копии из «Программ». Вернуть как было — в Finder: файл ▸ **Get Info** (⌘I) ▸ **Open with** ▸ нужная программа ▸ **Change All…**.

## Если что-то не так

**Нет подсветки Markdown** — у документа расширение не `.md`. Новый документ (⌘N) — простой текст: сохраните его как `.md` или создавайте из шаблона.

**Не появляется серая подсказка** — курсор не в конце строки, набрано меньше 2 букв, в документе нет подходящих слов от 4 букв, или выключено **Edit ▸ Suggest Completions**.

**Tab вставил табуляцию, а не слово** — подсказки в этот момент не было (серого текста не видно); Tab без подсказки работает как обычно.

**Кавычка не закрылась** — так задумано после буквы или цифры, чтобы не мешать апострофам и дюймам.

**Accept/Reject изменил весь документ** — ничего не было выделено. **⌘Z** отменяет.

**Окно не появилось, только иконка в Dock** — кликните иконку. Если не помогает: `defaults delete com.example.focusedit` (сбросит и настройки) и запустите снова.

**Приложение сразу закрывается, в отчёте `Code Signature Invalid`** — бандл испорчен ручным копированием бинаря. Пересоберите: `./package.sh`.

**В «Открыть с помощью» или Spotlight две FocusEdit** — это рабочие сборки из папки проекта. `./install.sh` убирает их из списка программ системы; если какая-то осталась, переустановите через `./install.sh`.

## Windows (эксперимент)

В папке `windows/` есть экспериментальная Windows-версия (подробно — [windows/BUILD.md](windows/BUILD.md)). Работает так же, с поправками:

| macOS | Windows |
|---|---|
| ⌘ | Ctrl |
| ⌘? — подсказки | **F1** |
| ⌃⌘F — полный экран | **F11** |
| ⌥Esc — список вариантов | **Ctrl+Space** |
| ⌘F / ⌥⌘F — поиск, замена | **Ctrl+F** (одна панель для поиска и замены) |
| ⌥⌘P — режимы Edit → Split → Preview (кнопка с глазом); **Esc** выходит из Preview | **Ctrl+Shift+V** — то же |
| ⇧⌘P — палитра команд: наберите, что нужно (тема, вид, экспорт, цель по словам, недавние файлы). Число в палитре: цель по словам или переход к строке | **Ctrl+Shift+P** — то же |
| выделить текст и вставить адрес `https://…` — получится ссылка `[текст](адрес)` | то же |
| **живая разметка**: знаки `#`, `**`, `*`, `~~`, `` ` ``, `[ ](…)` скрыты вдали от курсора и появляются, когда он рядом; заголовки крупнее. Выключается: **Modus ▸ Live Markup** или палитра «Markup» | то же (палитра «Markup») |
| ⌥⌘O — outline | **Ctrl+Shift+O** (кнопка со списком) |
| ⌘P — печать | **Ctrl+P**: окно печати, в нём же «Сохранить как PDF» |
| File ▸ Open Recent, экспорт | кнопка **⋯**: недавние файлы, Export as HTML, Print or save as PDF, Copy as HTML |

Это этап 2: фокус, печатная машинка, подсказки, автоскобки, списки, темы (в том числе «System» — по настройке Windows), файлы, восстановление после сбоя. Нет библиотеки, подсветки Fountain, CriticMarkup и звуков (Vim-режим, превью Markdown, outline, недавние файлы, экспорт и открытие перетаскиванием есть). Установщик (`.exe`) берётся из GitHub Actions: **Actions** → последний запуск **Windows build** → **FocusEdit-windows**.

## Чего пока нет

- Истории версий документа: при сбое текст восстанавливается, но прежних версий файла нет — сохраняйтесь через ⌘S.
- Синхронизации через iCloud и расширения Quick Look.
- Сценарной вёрстки страниц при экспорте Fountain в PDF.
- Режима «запретить удаление текста» из плана проекта.
